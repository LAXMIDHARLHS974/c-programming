# C Programming

A collection of C programming programs covering fundamental concepts, problem-solving, and practical examples. This repository is designed to help beginners build a strong foundation in the C programming language.

## 📚 Topics Covered

* Hello World
* Variables & Data Types
* Input & Output
* Operators
* Conditional Statements (`if`, `if-else`, `switch`)
* Loops (`for`, `while`, `do-while`)
* Functions
* Arrays
* Strings
* Pointers
* Structures
* File Handling
* Recursion
* Pattern Programs
* Searching & Sorting
* Practice Problems

## 🛠️ Technologies Used

* **Language:** C
* **Compiler:** GCC / Clang
* **IDE:** VS Code / CodeBlocks / Turbo C (optional)

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/LAXMIDHARLHS974/c-programming.git
```

### Navigate to the Project

```bash
cd c-programming
```

### Compile a Program

```bash
gcc filename.c -o output
```

### Run the Program

**Linux / macOS**

```bash
./output
```

**Windows**

```bash
output.exe
```
